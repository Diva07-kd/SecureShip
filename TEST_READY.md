## 6. Integration Contract with Downstream Agents

Downstream implementation agents (Backend implementer for M1/M2 and Frontend implementer for M3) can execute `pytest tests/e2e -v` continuously during development.

The test fixtures in `tests/e2e/conftest.py` are designed with progressive testability:
- When `backend.app.core.safe_extract` or `backend.app.main:app` is implemented, the test harness automatically imports and tests the live backend code directly against the identical strict invariants.
- If live HTTP server testing is desired, setting `SECURESCAN_API_URL=http://localhost:8000` switches endpoint tests to live HTTP transport.
